# 🛰️ GNC-DEBRIS-AVOIDANCE
**Système autonome d'évitement de débris pour CubeSats**  
*Algorithmes : Kalman + Détection de débris + Commande prédictive*

## 🚀 Fonctionnalités principales
- Filtrage de Kalman pour l'estimation d'état en orbite basse (LEO)
- Détection de débris (distance, historique, traçabilité)
- Simulation réaliste de mesures bruitées et de scénarios d'évitement
- Visualisation professionnelle des trajectoires, détections et distances
- Organisation professionnelle des expérimentations (par branche, logs, figures)
- Tests unitaires et CI pour chaque module clé

## 📁 Structure du projet
- `src/gnc/` : Code source principal (modules Python : Kalman, détection, contrôle...)
- `tests/` : Tests unitaires et d'intégration (`test_*.py`)
- `notebooks/` : Notebooks Jupyter pour l'exploration et la visualisation
- `experiments/` : Dossiers d'expérimentations traçables par branche (logs, figures)
- `scripts/` : Scripts utilitaires (ex : création automatique d'expérimentation)
- `debris_dataset/` : Jeux de données de débris
- `images/` : Figures et résultats globaux
- `run.sh` : Script de lancement principal
- `requirements.txt` : Dépendances Python
- `fiche_commandes.md` : Mémo des commandes utiles
- `Makefile` : Automatisation de la création d'expérimentations

## 🛠️ Installation des dépendances

Installez toutes les dépendances avec :
```bash
pip install -r requirements.txt
```

## ▶️ Exécution de la simulation principale

Pour simuler et visualiser le filtrage de Kalman :
```bash
./run.sh
```
Cela générera un graphique dans `images/trajectory.png` montrant :
- La trajectoire réelle du satellite
- Les mesures de capteur bruitées
- L'estimation du filtre de Kalman

## 🧪 Lancer les tests unitaires

Exécutez tous les tests unitaires avec :
```bash
pytest tests/
```

## 🧑‍🔬 Ajouter une nouvelle expérimentation (structure automatique)

Pour créer une nouvelle expérimentation avec la structure recommandée :
```bash
make new-experiment-<nom_branche>
# Exemple : make new-experiment-debris-avoidance-2d
```
Cela crée automatiquement :
- `experiments/<nom_branche>/`
- `experiments/<nom_branche>/figures/`
- `experiments/<nom_branche>/<nom_branche>_log.md` (template)

## 📖 Organisation des expérimentations

Voir `experiments/README.md` pour la description détaillée de chaque dossier d'expérimentation, la logique de traçabilité et la procédure recommandée.

## 🔬 Bonnes pratiques
- Créer une branche git dédiée pour chaque expérimentation
- Documenter chaque étape dans le log d'expérimentation
- Versionner les figures et scripts associés
- Utiliser la CI et maintenir la documentation à jour
