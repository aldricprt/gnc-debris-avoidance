# Fiche mémo : Commandes utiles pour le projet GNC Debris Avoidance

## Git (gestion de versions)

# Afficher la branche courante
 git branch

# Créer une nouvelle branche
 git checkout -b nom-de-ta-branche

# Ajouter tous les fichiers modifiés
 git add .

# Enregistrer un commit
 git commit -m "Message clair sur la modification"

# Envoyer la branche sur GitHub
 git push origin nom-de-ta-branche

# Mettre à jour ta branche avec la branche principale
 git pull origin main

# Supprimer une branche locale
 git branch -d nom-de-ta-branche

# Supprimer une branche distante
 git push origin --delete nom-de-ta-branche

## Tests et exécution

# Lancer tous les tests unitaires
pytest tests/

# Lancer le script principal
./run.sh

# Lancer Jupyter Lab pour exécuter les notebooks
jupyter lab

# Installer les dépendances Python
pip install -r requirements.txt

# Mettre à jour pip
pip install --upgrade pip

# Activer l'environnement virtuel (macOS/Linux)
source .venv/bin/activate

# Activer automatiquement l'environnement virtuel à l'ouverture du projet (optionnel)
# Ajoute ce bloc à la fin de ton fichier .bashrc ou .zshrc :
#
#   if [ -f "$PWD/.venv/bin/activate" ]; then
#       source "$PWD/.venv/bin/activate"
#   fi
#
# Ainsi, l'environnement virtuel s'activera automatiquement quand tu ouvriras un terminal dans le dossier du projet.
#
# (Pour désactiver, il suffit de commenter ou retirer ce bloc.)

## Astuces

- Vérifie que la CI (GitHub Actions) passe avant de fusionner.

## Créer une nouvelle expérimentation (structure automatique)
# Remplacer <nom_branche> par le nom de la branche/expérimentation souhaitée
make new-experiment-<nom_branche>

# Exemple :
make new-experiment-debris-avoidance-2d

## Ajouter une nouvelle figure ou log à une expérimentation
- Placer les figures dans `experiments/<nom_branche>/figures/`
- Compléter le log dans `experiments/<nom_branche>/<nom_branche>_log.md`

## Bonnes pratiques
- Créer une branche git dédiée pour chaque expérimentation
- Documenter chaque étape dans le log
- Versionner les figures et scripts associés
