# This folder contains unit and integration tests

## Description of the tests in `test_kalman.py`

- **test_kalman_convergence**:
  Checks that if the Kalman filter is initialized with the same value as the first measurement, the estimate remains consistent with the measurement (immediate convergence).

- **test_kalman_convergence_from_far**:
  Checks that the Kalman filter progressively converges to the measurement value, even if the initial state is very far. The test applies 100 updates to give the filter time to adjust.

- **test_kalman_with_noisy_measurements**:
  Checks the robustness of the filter to noisy measurements. After several updates with measurements centered around 10 (with noise), the final estimate should remain close to the mean of the measurements.

- **test_kalman_min_altitude**:
  Checks that the minimum altitude constraint is respected: the estimate never goes below the set value, even if the measurement is much lower.
